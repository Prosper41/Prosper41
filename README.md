### 🚀 Featured Work

#### ApexHR

A multi-tenant HR and leave management platform. Worked across the frontend, backend APIs, and deployment setup.

Implemented multi-step leave approvals, ledger-based leave balances, role-based permissions with tenant and department scoping, scheduled accruals, and audit logging. Set up CI pipelines and a Docker Compose development environment.

`Next.js` `NestJS` `CQRS` `Prisma` `MariaDB` `Redis` `RabbitMQ` `BullMQ` `Docker`

#### [Internal Developer Platform](https://github.com/Prosper41/idp-platform)

A self-service portal for managing infrastructure, applications, and environments.

Includes project and team management, role-based access control, environment and deployment management, secrets management, policy and approval workflows, audit logs, and an admin dashboard.

`Next.js` `NestJS` `PostgreSQL` `Prisma` `Redis` `BullMQ` `Docker`

#### Blood Donation Tracker

A mobile application connecting donors, hospitals, and blood banks through donor registration, appointment booking, donation history, and notifications.

Built the React Native mobile app and a companion Next.js admin dashboard, with Supabase handling authentication and data.

`React Native` `Expo` `Next.js` `Supabase`

#### TradeArena

A virtual trading application focused on the Ghanaian market, using seeded price data and a starting virtual balance of GH₵100,000.

`Angular` `NestJS` `PostgreSQL`

#### Multiplayer Browser Game

A browser-based 3D game with account registration, login, player information, and an online player view.

Combines a Next.js interface and Three.js experience with a Django backend and PostgreSQL database.

`Three.js` `Next.js` `Django` `PostgreSQL`
